# Passage à NoChoice Alarm 1.5.3

## Correction

Une alarme désactivée est désormais automatiquement réactivée lorsqu’elle est enregistrée depuis l’écran d’édition.

Le bouton ON/OFF de la liste reste indépendant : une désactivation effectuée depuis la liste est conservée tant que l’alarme n’est pas à nouveau enregistrée dans l’éditeur.
